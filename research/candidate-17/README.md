Candidate 17 reuses Candidate 16 v2's NautilusTrader execution/accounting path and changes only the market-state policy.

1. **Clean first-defense rejection:** one parent observation, zero outside closes, displayed defense, reclaim, then a strictly later opposite initiative.
2. **Remembered-defense depletion:** repeated/outside interaction or a re-accessed clean failure suppresses reversal. Continuation requires a close beyond the prior extreme, directional flow/return, higher price-impact efficiency than the first attack, weaker top-depth defense, withdrawal in broader depth, and fresh positive five-minute OI change. Entry waits for the first defended retest.
3. **Unresolved:** every incomplete or conflicting state is no-trade.

No new backtester, account engine, target fallback, or PnL-trained threshold is introduced.
