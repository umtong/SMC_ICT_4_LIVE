# Candidate 14 L1 연속 홀드아웃 실패 분석

## 최종 판정

Candidate 14는 폐기한다. 전략 소스는 동결된 상태로 `2026-05-11`부터 `2026-08-03`까지 84일을 하나의 NautilusTrader 계좌에서 연속 평가했고, 다음 결과를 기록했다.

- 시작 NAV: `100,000 USDT`
- 종료 NAV: `80,737.93761302 USDT`
- NAV 배수: `0.8073793761x`
- 비용 후 일평균 기하성장률: `-0.254392%`
- 종료 거래: `15`
- 승/패: `3 / 12`
- 승률: `20.0%`
- 승률 Wilson 95% 구간: `[7.05%, 45.19%]`
- 평균 이익 / 평균 손실: `1.6896`
- 연속 실현 거래경로 최대낙폭: `21.3861%`
- 활성 주간: `9 / 12`
- 최장 연속 무거래 주: `1`
- 한 주의 양의 로그성장 최대 기여: `48.2854%`
- 최장 연속 손실: `7거래`

모든 구현·계산·위험예산·글로벌 단일 슬롯·부분체결·청산·엔진 감사가 통과했다. 따라서 이번 실패는 실행 인프라가 아니라 전략 논리와 기회 구조의 실패다.

## 핵심 실패 메커니즘

### 1. 동기화된 단기 반응을 통제권 이전으로 오인했다

체결된 SCDAM FAR 10개는 모두 `SEMANTIC_FAR_MODERATE_COUNTERTREND_UNANIMOUS`라는 같은 의미 상태로 승인되었지만 3승 7패였다. 즉 이 상태 라벨은 다음 두 경제 상태를 분리하지 못했다.

1. 기존 경매가 실제로 실패하고 반대편이 새 통제권을 획득한 경우
2. 기존 방향성 경매 내부에서 네 시장이 동시에 청산·되돌림한 경우

peer 세 종목이 sweep 이후 같은 방향으로 움직였다는 사실은 공통 충격을 보여줄 뿐, 기존 inventory가 소진되었거나 dominant leader의 경매가 무효화되었다는 증거가 아니다. 현재 게이트는 결과 시점의 동조·순위·변동성 정규화 이동을 측정하지만, 누가 먼저 외부 유동성을 회수했고 어느 시장의 acceptance가 먼저 실패했는지에 대한 causal ownership과 chronology를 충분히 표현하지 않는다.

### 2. 단순한 강도 임계값 부족이 아니다

명백히 약한 FAR 손실도 있었다.

- `2026-05-19 XRP long`: event rank 3, trailing rank 4, path efficiency `0.033`, standardized displacement `0.216`
- `2026-06-08 XRP short`: efficiency `0.016`, displacement `0.161`
- `2026-06-15 SOL short`: efficiency `0.065`, displacement `0.265`

그러나 강한 측정값을 가진 손실도 있었다.

- `2026-07-03 XRP short`: event rank 1, efficiency `0.667`, displacement `2.519`, terminal impulse `2.688`
- `2026-07-20 BTC short`: efficiency `0.598`, displacement `2.437`, terminal impulse `1.925`
- `2026-05-29 ETH short`: event rank 1, terminal impulse `6.820`

따라서 event rank, efficiency, displacement 또는 impulse의 숫자 하나를 강화하는 방식으로 해결할 수 없다. 약한 사례를 제거해도 강한 거짓 전이가 남는다. 누락된 것은 연속값 임계치가 아니라 경매의 범주적 상태다.

### 3. AAC 지정가에는 구조적인 adverse selection이 있었다

AAC 계획은 6개였고, 3개는 체결되지 않았으며 체결된 3개는 모두 손절됐다. passive defended-pullback 지정가는 좋은 가격을 주는 중립적인 체결 장치가 아니다.

- 강한 acceptance가 즉시 계속되면 지정가가 체결되지 않는다.
- 가격이 defended pivot 또는 source boundary까지 깊게 되돌아올 때만 체결된다.
- 그 되돌림 자체가 acceptance 약화 또는 실패의 정보일 수 있다.

특히 `2026-07-09 BTC long`과 `2026-07-20 XRP short` AAC는 진입 전 이미 같은 방향의 외부 유동성들이 소비되고 draw가 재구성된 뒤였다. source boundary 밖에 있다는 사실만 유지한 채 경매의 나이, 동일 방향 목표 소비량, terminal expansion 여부를 구분하지 못했다. 그 결과 maker 가격 개선이 아니라 실패 중인 acceptance를 조건부로 선택했다.

### 4. Session I7의 짧은 주간 성공은 현재 레짐으로 이전되지 않았다

I7에서 승인·체결된 두 계획은 high acceptance와 high rejection 하나씩이었고 둘 다 약 `-1R`이었다. 네 시장 의미 게이트를 통과했음에도 반대 시나리오 둘이 모두 실패했으므로, 특정 route 하나의 사소한 오류로 설명할 수 없다. 이전의 7일 표본에서 관측된 I7 성공은 현재 연속 레짐에서 재현되지 않았다.

### 5. 거래 수보다 레짐 블록이 실제 독립 표본에 가깝다

손익 순서는 다음과 같았다.

```text
L, W, L, L, L, L, L, L, L, W, L, L, W, L, L
```

한 번의 cascade에서 중복 진입한 것은 아니지만, `2026-05-19`부터 `2026-06-24`까지 7연패가 이어졌다. 이는 서로 독립인 Bernoulli 거래 7개라기보다 같은 잠재 상태가 여러 주 지속된 regime block에 가깝다. 무작위 1주씩 떨어뜨려 평가하면 이런 직렬 상관과 회복 경로가 잘린다.

### 6. 위험률·수수료·체결이 원인이 아니다

12개 손실의 대부분은 계획손실예산의 약 `-1R`에서 종료되었다. 평균 승리는 `1.6896`배의 평균 손실을 만들었지만, 손익분기 승률 `37.18%`에 비해 실제 승률이 `20%`였다. 80%가 진짜 승률이라고 가정할 때 15회 중 3승 이하가 나올 확률은 약 `0.000101%`다.

3% 위험 산정은 계획대로 작동했고 강제청산도 없었다. 위험률을 낮추면 손실의 크기만 감출 뿐 음의 기대값은 해결하지 않는다.

## 왜 개발 무작위 주간은 좋아 보였는가

V5 개발 표본은 서로 떨어진 5개 주, 35일, 8거래, 8승이었다. L1은 규칙을 바꾸지 않은 채 최근 84일 연속 구간에서 3승 12패였다. 이 차이는 다음이 동시에 작동한 결과다.

1. 날짜가 무작위여도 그 날짜에서 버전·분기·임계값을 선택하면 개발 표본이 된다.
2. 통과 후보만 다음 단계로 보내는 반복 중단 규칙이 winner's curse를 만든다.
3. 떨어진 주간은 지속되는 adverse regime과 연속 손실을 잘라낸다.
4. 희소한 8전 8승은 손실 상태의 발생률을 추정하지 못한다.
5. 같은 FAR/AAC 라벨 내부에 서로 다른 inventory/acceptance 상태가 혼합되어 있다.
6. cross-market 동조는 인과적 통제권 이전이 아니라 공통 청산 반응일 수 있다.

개발 8전 8승과 L1 3전 12패의 차이는 동일한 안정 승률에서 나온 단순 표본 변동으로 보기 어렵다. 그러나 개발 표본은 반복 선택을 거쳤으므로 이 차이를 정식 통계 검정으로 일반화하지 않는다. 핵심은 L1이 성공 가설을 직접 반증했다는 사실이다.

## 연구 결정

- Candidate 14는 성공 후보가 아니다.
- L1 결과를 보고 `event_rank <= 2`, 특정 session whitelist, XRP 전용화, 임의 efficiency cutoff 등을 추가하지 않는다.
- 그런 규칙은 모두 L1 사후 부분집합 과적합이 된다.
- L1은 후속 후보의 개발 자료로만 사용할 수 있으며 Candidate 14의 홀드아웃으로 재사용하지 않는다.

후속 후보는 숫자 필터가 아니라 다음 상태를 새로 표현해야 한다.

```text
외부 유동성 원인의 고유 identity
→ dominant leader의 선행 sweep/acceptance/rejection chronology
→ 기존 inventory 경매의 명시적 무효화
→ 새 initiative가 소유한 entry leg
→ 같은 leg가 소유한 invalidation과 아직 살아 있는 objective
→ 동일 economic episode의 중복 신호 억제
```

Acceptance 시나리오는 추가로 경매의 나이, 이미 소비한 동일 방향 draw 수, pullback 체결의 adverse-selection 의미를 상태에 포함해야 한다. 이 구조가 먼저 성립하지 않으면 더 많은 확인봉이나 더 엄격한 수치 임계값은 선택성–지연 문제만 악화시킨다.
